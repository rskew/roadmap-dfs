Which big-screen proposal first?

Eight ways to give the roadmap a good big-screen experience are written up as parked nodes. The recommendation assumes one setup: a phone docked to a monitor, driven by a game controller. Change the setup to see what would come first instead.

    What would show it wrong

    The big screen is a mirror of the phone (so no wider page ever reaches it), or a second device or nothing at all drives it, so a controller layer on the page is not what is wanted.

    The evidence so far

    On 1920 and 3840 px screens today the page stays 1180 px wide and 17 px type, and nothing reads a gamepad: both pieces are unbuilt, so they are the gap for the docked and controller case. Android 16 desktop mode on a Pixel 8 or newer or a recent Samsung gives a phone floating windows on an external monitor, so a browser there gets a desktop-width page; the search found no iPhone equivalent, only mirroring, so for an iPhone the wide layout does not arrive and the mirror or remote proposals apply.
