W182.2: one plus button on every width

Goal: Add task is a plus button at the bottom right, above the bottom row. Two readings went into the work without being stated. Switch the screen to see each.

The two assumptions

1. Wide screen. The tab bar is at the top there, so there is no bottom row. The wide screen had a text button "Add a task" at the bottom right. The work turned it into the same "+" so both sizes match. Wrong if you wanted the wide button to keep its words.

2. Phone. The old phone code carried a comment that a floating button covered the badges of rows scrolling under it, on 14% of scroll positions of a 153-task list. That is why the phone had a tab. The plus button brings the cover back. It is 52px square, and the last row has a gap so it can be scrolled clear. Wrong if the cover hides badges you need. The browser flow could not run here (no node). A headless chromium screenshot of the real page showed the button at the bottom right on both sizes, but the list was not scrolled under it, so the cover itself was not seen.
