Does one pinned row keep the task in view?

An opened node in the terminal tree can be 83 lines long and fill the pane, so the task's title and status scroll out. The change puts the task id, status and sessions in the pane's rule (the grey line above the tree), the one row that never scrolls. Pick a screen to see that row as drawn by the real UI.draw (recorded in docs/ux-tui-pane.txt).

Refute this if the name is clipped or overwritten at a width you use, or if you would rather an opened node were capped and scrolled inside itself than have the task shown on one row.

The other layout

Cap an opened node's height and scroll within it: the title and status lines stay in the pane, but a long node shows less at once and needs a second scroll. It was not built or drawn, so only the pinned row is evidence here.
