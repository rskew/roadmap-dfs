Does a claude at its limit say so, in words the check reads, before it goes quiet?

After a message is typed at a limit, the relay watches what claude draws. If the words say it is still at the limit (or the menu comes again) the limit stays. If claude answers and then goes quiet for a second with no such words, the relay takes the limit as lifted and the page drops its line. It waits at most 120 seconds and leaves the limit as it is if claude is still going. Pick what claude does.

  • Against: "Session limit reached" and "5-hour limit reached" are not in any real log here. The squashed check reads "limit reached" in any wording, but a claude that says it another way would still be missed.
  • The wait is no longer a fixed 10 seconds: the relay decides when claude has finished, so a slow answer is not mistaken for a lifted limit. No real log holds a message typed at the menu after Esc, so the answer's wording there is read from the W68 one.

Wrong if a real claude at its limit answers a typed message with words the check does not read and then goes quiet: the page drops the limit line while claude is still at the limit. The message still reaches claude, which answers it, so the chat does not hang again; only the page's limit line is wrong until the menu is drawn again.
