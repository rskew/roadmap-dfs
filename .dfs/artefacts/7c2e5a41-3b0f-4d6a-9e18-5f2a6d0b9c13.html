How Stop reaches a chat the screen runs

A chat started on the page is a real interactive claude the screen keeps on a pseudo-terminal. Stop has to end the answer it is giving without ending the conversation. Pick a way to see what each does.

The way Stop is sent

Does claude honour a lone Esc?

What would show it wrong

On a real claude answering in the background, Stop leaves it still answering (Esc is ignored), or the claude exits (the conversation would then resume on the next message, but the turn is lost).

The evidence so far

Not observed here: this sandbox has no claude binary. test_ptyrelay shows the ESC byte reaches a process on the pty and that queued messages are dropped; that claude acts on it is claude's documented behaviour (Esc interrupts a running turn) and has not been run.
