ptyrelay.py: a chat, an interactive agent kept running with nobody looking

Tasks W17 and W90. A Relay runs one agent on a pty (a pseudo-terminal: a fake screen and keyboard a program can hold). The web page types into it with send; the terminal screen can attach to it and detach again. ChatHost keeps one Relay per scope (a task id, or project) and closes the idle ones.

How to read these pictures

Colour is the lens. A box is a thing, an arrow is something that happens to it. Each box has a symbol in front, each arrow a head at the end, so nothing depends on colour alone.

Boxes

  • ƒfunction code in the files read
  • ◉actor a person or program outside these files
  • ▤store a file or directory holding data
  • ◆state a value that is remembered and changes
  • ⬢resource something opened that must be let go
  • ≣queue things waiting, taken in order

Arrows

  • moves▶ a value travels from one to the other
  • sets▶ the left one changes the state on the right
  • reads▶ the left one looks at the state on the right
  • acquires● the left one takes hold of the resource
  • releases○ the left one lets the resource go
  • fails▶ a failure travels on to the right
  • stops■ a failure ends at the right: nobody further out hears of it
  • puts▶ the left one adds to the queue on the right
  • takes▶ the left one removes from the queue on the right
  • handles▣ the left one catches an error and does what the label says

in f at the end of a row names the function whose code does it. The tree above lists the same functions.
