What the Hypothesis says

Trading late-starting parallelism for a full cap is acceptable: a lone task should run as long as one worker would let it. It is wrong if a work is expected to start a task that appears mid-chain on a free worker at once. Then the cap would be lowered while it runs (as work_lower does), or a share kept back.
