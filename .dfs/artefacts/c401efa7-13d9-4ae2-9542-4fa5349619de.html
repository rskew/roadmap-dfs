Does a real body always arrive inside one second?

Since W184.1, tree.py log and add wait one second for a body on stdin and drop one that starts later or goes quiet for a second. The assumption: every real writer is quick. Pick a writer to see what the code does.

Green is the first second (the wait). Red is when the writer's text arrives (axis 0 to 3 seconds).

What was checked

Run against read_body() as committed: heredoc, echo and a 0.7s writer arrive whole. A 2s late writer gives an empty body and exit 0. A writer that stops for 2s gives only the first line. Neither prints a message. SKILL.md and the repo docs only show heredocs.
