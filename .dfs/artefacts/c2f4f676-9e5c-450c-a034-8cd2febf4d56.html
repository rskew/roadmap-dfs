One installed icon for the project

The task asks for a custom installed icon "similar to the background". The background has one picture per light and dark mode. I made one icon for the project and listed it in the manifest as three any icons that all point at that picture. Tap an option to see what each choice changes.

How the icon is asked for

Phone home screeniOS reads only the apple-touch-icon link
Chrome installreads /manifest.json, wants a 192 and a 512 icon
Serverone fetch, no light or dark mode sent

Evidence so far

  • For: the web search says Chromium installs with a 192 and a 512 icon, and iOS ignores the manifest icons and uses apple-touch-icon.
  • For: the manifest and the apple-touch-icon are fetched by the system, not by the page, so neither can know whether the page is in dark mode.
  • For: test_the_installed_icon_is_set_served_everywhere... passes with this manifest.
  • Against: the existing installability test wants a maskable icon (Android 12 builds its launch icon from one). A custom icon has none, so Android shrinks it onto a plain backdrop.
