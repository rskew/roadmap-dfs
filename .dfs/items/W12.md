# W12 · Confirmed/refuted assumption shouldn't show as flagged

## Summary

A node whose assumption the author has confirmed or refuted by a correction no longer shows as flagged: the terminal tree, its "next flagged" jump, the web page's rows and Flagged count, the assumptions list and the accept question all leave it out, and agent-refuted or pruned nodes were already left out. An assumption the agent confirmed itself is still flagged, since the author has not yet ruled on it and is meant to review those when accepting the tree. The Goal was read that way because the flag exists to ask for the author's attention, which their own ruling answers.

## Goal

Confirmed/refuted assumption shouldn't show as flagged

## Tree

### W12.1 · Clear the flag once the author has ruled on the assumption
Status: confirmed
Approach: `dfs_tree.assumed` (tree.py) leaves out a node the author has a confirmed or refuted correction on; `tree_entries` (tui.py) carries `assumes`/`asks` per row from it, and the terminal row, the next-flag jump and web.py's row JSON read those instead of testing the status themselves. Tests: test_tree (assumed drops a ruled node, either verdict) and test_screen (the row carries neither flag).
Hypothesis: "Confirmed/refuted assumption" means the author's confirmed or refuted correction, not the agent's own confirmed status, because the flag asks the author to look and an agent-confirmed assumption is exactly what they review when accepting. Wrong if the author wants every node with a confirmed status unflagged too.
Evidence:
- for: before the change an author-confirmed node still listed in `dfs_tree.assumed` (only author-refuted was excluded, via effective status); after it, test_tree's new test passes for both verdicts.
- against: none found; an agent-refuted or pruned node was already unflagged in the terminal and web.
Determination: Confirmed: a node the author has ruled on is no longer flagged anywhere, and the Goal is met on that reading.
Ask: Should an assumption the agent itself marked confirmed also stop being flagged, or stay until the author rules? I kept it flagged.
