# W58 · Raise artefacts should answer via form submission

## Summary

A raise or an assumption can already be answered from its artefact: the answer-page template posts a raise's answer or a node's confirm or refute through the page's one route, and the checker refuses a page that cannot. This work rewrote the artefact directives (docs/artefacts.md and the Raising and Hypothesis passages of SKILL.md) so each rule is stated once, in the order a writer needs it, and dropped references to files and a README section that do not exist. The Goal was met by the existing mechanism, so no behaviour changed; the rewrite only changes the wording of the directives.

## Goal

The user should be able to answer a raise from the artefact itself. Similarly with refuting or confirming an assumption.
