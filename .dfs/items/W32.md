# W32 · Allow customizing the background per app, not the top colour line

## Summary

Each project can now have its own page background, chosen in the project dialog on the web page and kept in `.dfs/background`, separately from the colour that marks the top line, which is unchanged. The page takes light or dark text to match the background (at least 4.5:1 for text and secondary text), so the light/dark switch is hidden while a background is chosen, and clearing it returns the design's paper. The status colours (blue, red, amber) are not adjusted to the chosen background, so an unusual background can weaken them. The terminal screen was not changed.

## Goal

Allow customizing the background per app, not the top colour line
