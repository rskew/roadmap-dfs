# W32 · Allow customizing the background per app, not the top colour line

## Summary

Each project can now have its own page background for light mode and another for dark mode, chosen in the project dialog on the web page and kept in `.dfs/background`, separately from the colour that marks the top line, which is unchanged. The light/dark switch stays and picks which of the two backgrounds the page wears; a mode with none keeps the design's own paper. Text and secondary text are chosen to keep at least 4.5:1 on whatever background is set. The status colours (blue, red, amber) are not adjusted to a chosen background, so an unusual one can weaken them. The terminal screen was not changed.

## Goal

Allow customizing the background per app, not the top colour line
