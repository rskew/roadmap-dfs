## Summary

The task's logs and run records were read and counted, and the findings are raised for the author. The tooling faults found are fixed: a kiro session's context is measured from the percentage its stream carries instead of recorded as 0, and a session with no reading still counts its turns so the fallback ceiling can stop a runaway chain. The window used to turn kiro's percentage into tokens is stated as an assumption with a page: it is the largest estimate from the breakdown, snapped to a known size, because the median had picked 200k in 3 of 54 real runs and under-reported the peak fivefold. The first raise wrongly called W86 and W97 untouched, since it read only the default branch; the second raise corrects that.
