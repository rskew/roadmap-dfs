# W96 · Can't reorder an item above a break

## Summary

In the web page's Reorder mode, dragging a task by its grip can now drop it on either side of a break: just above the rule makes it the last task of the segment above, and just below makes it the first of the segment below. Before, the two gaps beside a break counted as one, so no drag could put a task at the end of a segment, and the task next to a break could not be dragged across it at all. The keyboard arrows, the terminal's `[`/`]` and the server already handled breaks correctly, so only the page's drag code changed. A browser test now covers dragging across a break in both directions.

## Goal

Can't reorder an item above a break
