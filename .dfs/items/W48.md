# W48 · Chat in the tui has weird line wrapping since we added the background chat sessions

## Summary

A chat that runs in the background starts at the size of the screen's terminal, follows its resizes, and now keeps the terminal's private modes (alt screen, mouse, bracketed paste, focus) in step when you attach and detach. A real claude driven through the relay and through the tui's `c` showed the same visible screen as claude run directly, wrapped at the terminal's width, so no cause of the weird wrapping was found and the Goal is not shown to be met; the fixed-width start, a clear on attach and a replay were tried against it and none changed the screen. What the real runs did show were two defects, both fixed: attaching to a chat that had already ended crashed the screen, and attach left a narrower frame in the scrollback and claude's mouse modes on after detach. The ctrl-] hint that attach's clear wiped is no longer printed; the key help for `c` now says ctrl-] comes back and leaves the chat running. Whether the fixes were what the author saw is for them to check in a real chat.

## Goal

### W48.11 · Fix: `Relay.attach` on a chat that has already ended raises TypeError and ends the screen
Parent: W48.10
Status: confirmed
Approach: `fit` in `Relay.attach` (scripts/ptyrelay.py) passes `self.fd` to `fcntl.ioctl`; once the agent has exited `_pump` sets `self.fd = None`, and `_try` catches OSError, ValueError and termios.error but not the TypeError that gives, so the traceback ends the curses screen. Make `attach` return False when the chat has no fd (read `self.fd` once), and `Relay.resize` already returns on None. Add a test in scripts/test_ptyrelay.py: a Relay whose agent exits at once, then `attach()` returns False and does not raise. Check: the test is red on the current code and the suite passes.
Determination: `Relay.attach` returns False at once for a chat that has already ended, and `fit` reads `self.fd` once and does nothing when it is None, so the TypeError no longer ends the screen; the new test (attach to an agent that exited with 127) raised the TypeError on the old code and passes now, and test_ptyrelay.py passes (29 tests).
