# W42 · How are uncommitted changes attributed? They show on many items

## Summary

An item's "uncommitted" tag is now attributed by what changed in its task file. Changes outside the log read "edits"; log entries other than the runner's own session and end lines read "log"; and the runner's lines alone tag nothing, since one chain writes them to every task it runs and only a node commit of that same file takes them. A review's notes still show, labelled as log entries, so items holding only those stay tagged; whether such notes should show at all was my choice, and the node states it so the author can reverse it.
