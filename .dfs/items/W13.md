# W13 · Show when page is loading

## Summary

The web page now says when it is loading. Before the first draw it shows "Loading…", and once any request has been outstanding for a quarter of a second it shows a "loading" label and a sliding stripe under the header (still under reduced motion) and marks the view busy; fast reads and live updates show nothing. If the first load fails, the "Loading…" is replaced by the error and a Retry button, so the page never claims a wait that has ended. The terminal screen was left alone because it reads local files and has no wait. The Goal was fully met for the web page.
