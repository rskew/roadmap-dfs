# W77 · Codex logs don't show

## Summary

A run on the web page used to open only the chain's console, which under codex holds just the runner's own lines while the session itself streams into a file the page never read. Each session a chain ran is now a tab beside the console, drawn the way the terminal's log pane draws it (what the agent said, the commands it ran and what they printed), and a live one keeps growing; claude, kiro and opencode sessions get the same tab, claude's showing its final result. The Goal is met as I read it, taking "codex logs don't show" to mean the web page; the terminal screen already showed codex 0.162.1 sessions correctly here, so it was left alone. The author's own codex runs live in other projects, so the fix was checked against a real codex stream's shape and not against those runs.
