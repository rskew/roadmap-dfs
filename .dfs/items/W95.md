## Tree

### W95.1 · All four walk fields in the walk box, and Start walk starts at once
Status: refuted
Approach: In `scripts/web/index.html`, `walkHtml()` draws Budget (`#bud`) and Chains at once (`#par`) as rows of the walk box under Next and Agent while the walk is off, with the permission-prompts sentence beside Start walk; the `walkstart` act posts `/api/walk/start` with those two values straight from the box, and `walkStartForm()` and its modal go. What is typed in the two number fields is kept in `S` so a push that redraws the list does not wipe it. The `walk` flow in `scripts/ui_flows.mjs` fills `#bud` in the box and starts with no dialog; run it and `test_web.py`.
Hypothesis: Starting the walk needs no confirming dialog once every field is in the box: the box is opened on purpose and its button is labelled, and the warning about permission prompts can sit beside the button. Wrong if the author wants a second, deliberate step before agent sessions start with their prompts off. .dfs/artefacts/f456ae60-6cdb-4d45-ac41-2fd3dc530b91.html
Evidence:
- for: `test_ui.Flows.test_the_walk_controls` passes with the `walk` flow filling Budget 7 and Chains 2 in the box and starting with no dialog open; the walker got chains capped 3 and 4. With `S.walkDraft` dropped, the flow goes red ("a redraw of the list keeps what was typed in the box: 20 != 7").
- against: `walk_toggle`'s docstring in `scripts/tui.py` says "The prompt is also the confirmation … this starts chains until the budget or the tree runs out, so a bare keypress is not enough of a decision", and the web box remembers being open (`sessionStorage` `walkOpen`), so here Start walk is one tap.
- ![The walk box on a phone with Next, Agent, Budget and Chains and Start walk](.dfs/artefacts/aa9e616f-f28c-4172-9e7e-6834d41bad43.png)
Determination: Refuted: the fields belong in the box, but the author's rule that starting a walk takes a deliberate second step rules out a Start walk that starts on one tap; the fields move in this node's commit stays and the confirm comes back with none.
