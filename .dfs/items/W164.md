# W164 · Ending the project chat should cause a new chat to be created next time project chat is pressed

## Summary

Ending the project chat now means the next press of "Chat about the project" on the page, or `C` in the terminal, starts a new conversation instead of resuming the ended one. Task chats are unchanged, and the ended project chat still shows in the Chats list and opens its old conversation from there. I read "pressing project chat" as those two buttons, not the list row, so the old conversation can still be read. The page's browser flow was not run here because there is no node.

## Goal

## Tree

### W164.1 · Start a new project chat after the old one was ended
Status: confirmed
Approach:
- **The question**: after the project chat is ended, which presses of "project chat" start a new conversation instead of resuming the ended one?
- **Why it matters**: today End keeps the conversation (`Chats.end` in `scripts/chat.py`), so `Chats.open` (page) and `claim` (terminal `C`) resume it.
- **What this node does**: adds `Chats.renew_ended(scope)`, which calls `clear` when the scope is `project` and the chat is ended. The page's "Chat about the project" button sends `fresh` to `/api/chat/open`, and `Chats.open` calls it. `tui.py open_chat` calls it for `C`. Task chats and the ended row in the Chats list are unchanged. Tests go in `test_chat.py` and `test_review_tree.py`, and a page flow in `ui_flows.mjs`.
- **How we will know it worked**: a test ends a project chat, then opens it fresh, and sees a new session; opening the ended row, and a task chat after End, still resume.
Hypothesis: "Pressing project chat" means the "Chat about the project" button and `C`; the ended row in the Chats list still opens the old conversation to read it, and only the project chat is affected, not task chats. Wrong if the author wants End on the project chat to delete the conversation, or the ended row to start fresh too. .dfs/artefacts/43e29dd8-e91d-470c-aef3-2469dc14d02e.html
Evidence:
- for: grep of scripts/ for the project chat's entry points found three: the Chats tab's "Chat about the project" button, the ended and in-progress rows (which carry scope `project`), and `C` in tui.py. The button and `C` are the "press project chat" of the Goal; the rows open a listed conversation.
- for: test_chat passes with the change, and its two new tests show an ended project chat gets a new session on a fresh open, is kept on a plain open, and a task chat is resumed after End.
Determination: An ended project chat now starts a new session when the page's "Chat about the project" button or `C` opens it, and the Goal is met; task chats and the ended row are unchanged.
