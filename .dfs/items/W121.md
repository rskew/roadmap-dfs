# W121 · Option to show archived tasks

## Summary

The web page's task list now has a Show archived button (remembered in the browser) that draws archived tasks after the live ones, marked archived. An archived task opens read-only: its tree, nodes and artefacts can be read, and no answer, accept, edit, add or delete control is offered. The server reads archived tasks straight from their archive folder, apart from the live list, so the walk and runner never see them. Only the web page was covered: the terminal screen has no archive action and still does not list them, and a page screenshot showed no text here (no fonts), so the layout was checked from the page's contents.
