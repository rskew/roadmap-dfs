# W182 · Add task should be a plus button in the bottom right above the bottom row rather than in the bottom row

## Summary

Add task is now a plus button floating at the bottom right, just above the bottom tab bar on phones and with nothing under it on wide screens. The "Add task" tab is gone from the bottom row, and the button's accessible name is "Add task". The page-source test passes (the other five `test_web` failures were already failing). A headless chromium screenshot of the real page shows the button at the bottom right on both sizes. The browser flows could not run because `node` is not installed, so the new wide-screen check in the `newtask` flow, the other phone flows and the badge cover on a scrolled phone list were not run or seen. The wide screen also got the plus (its old "Add a task" text button is gone) and the phone again risks covering a row's badges; both are open for you to rule on.

## Goal

Add task should be a plus button in the bottom right above the bottom row rather than in the bottom row

## Tree

### W182.1 · Show Add task as a plus button at the bottom right on every screen size
Status: confirmed
Approach: **The question**
- The phone shows "Add task" as a tab in the bottom tab bar and wide screens show a floating "Add a task" button. How do both become one plus button floating at the bottom right, above the tab bar?

**What this node does**
- In `scripts/web/index.html`: drop the `tab-add` tab and its two media rules. Show the existing floating `.fab` button on every width, as a square 52px-tall button with a `+` and `aria-label="Add task"` (no word). Keep `.fab-gap` visible so the last row is not hidden under it.
- Update `test_the_phone_page_keeps_its_small_faults_fixed` in `scripts/test_web.py` and the `newtask` flow in `scripts/ui_flows.mjs` to match.

**How we will know it worked**
- `test_web.py` passes. The `newtask` flow checks the button is tap-sized, fixed, at the bottom right and above `#tabs`, and the tab bar has no Add task tab (the flow needs a browser; if none starts here, I say so).
Determination: The Add task tab is gone and a square "+" button now floats at the bottom right above the tab bar on every width; the page-source test passes and the browser flow could not run here (no node), so the layout is unseen.
