# W125 · Allow choosing models to use for walk

## Summary

The walk can now choose the models its claude sessions run on: one for planning (the first session on a task, the critic and the review) and one for implementing. They are set with `:model plan <name>` on the screen or the Plan and Implement model fields on the web page, kept for the next screen, and handed to every chain the walk starts; unset, the runner's opus and sonnet still apply. The Goal was met for claude only: codex, kiro and opencode still read their model from their own config, because the runner passes them no model flag and none is tested. The walk header does not show the choices (`:model` alone does), and the page's script could not be run here (no node), so the web fields are covered by the endpoint's tests alone.

## Goal

Allow choosing models to use for walk
