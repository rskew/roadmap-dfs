# W192 · Collapsed nodes should show when there are raises, incomplete nodes or assumptions underneath them

## Summary

A folded node now shows how many open raises, unfinished nodes and assumptions are hidden below it, in both the terminal screen (`scripts/tui.py`) and the web page. The counts are worked out by the shared `tree_entries` and sent to the page by `scripts/web.py`, so the two agree. Unfinished means open or started and still in play; parked, refuted and pruned nodes are not counted. The Goal is met. The page's chip code was not run in a browser or under node, since neither is available here; the server side that feeds it is tested.

## Goal

Collapsed nodes should show when there are raises, incomplete nodes or assumptions underneath them

## Tree

### W192.1 · Count raises, unfinished nodes and assumptions under a node, and show the counts on a collapsed row in the terminal screen and the web page
Status: confirmed
Approach: **The question**
- A folded node hides its descendants. Today its row says only how many open raises are hidden. How does it also say how many unfinished nodes and assumptions are hidden?

**What this node does**
- In `tree_entries` (`scripts/tui.py`) give every node that has children `under`: the number of open raises, of live unfinished nodes (status open or started, not dormant, parked, refuted or pruned) and of live nodes that state a Hypothesis (`dfs_tree.assumed`), counted over all its descendants whether or not it is folded.
- The terminal screen shows `under` on a folded row, red for raises and amber for the rest (`● 2 raises below  ○ 3 unfinished below  ⚑ 1 assumption below`). The row's colour follows: red if raises, amber if only assumptions.
- `task_json` (`scripts/web.py`) sends `under`; the web page (`scripts/web/index.html`) draws the same chips on a folded row, replacing its own raise counter.

**How we will know it worked**
- New tests in `scripts/test_review_tree.py` and `scripts/test_web.py` build a tree with an open raise, an unfinished node and an assumption three levels down, and check the counts on the folded and unfolded root. They fail on the old code.
Determination: Done: a folded row now counts the open raises, unfinished nodes and assumptions below it in the terminal screen and the web page; the new tests pass and the terminal ones fail on the old code. The page's own JavaScript could not be run, as no node is installed here.
