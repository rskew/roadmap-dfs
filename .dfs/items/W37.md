# W37 · Artefacts should be path-based links rather than just the filename in a raise

## Summary

A raise can no longer name an artefact by its bare filename: `tree.py log raise` refuses one, and says to write `.dfs/artefacts/<name>`, which is the form the web page turns into a link. The same holds for the page on an `Answer with:` line. SKILL.md and docs/artefacts.md say so. The Goal was read as being about what a raise is written with, so the web page still does not link a bare filename in a raise already in a log, and the localhost URL form is still accepted.

## Goal

Artefacts should be path-based links rather than just the filename in a raise
