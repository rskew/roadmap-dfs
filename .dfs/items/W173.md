# W173 · move the item log into a separate file that isn't loaded by default

## Summary

Each task's log now lives in `.dfs/items/<task>.log.md` (`<task>/<tag>.log.md` on a branch), so the task file a session reads holds the Goal and the Tree and no longer grows with every runner line. `load` merges the log file with any `## Log` left in a task file and the archive, and the commit guard (also at a rebase stop), the edit classifier, archive, audit, history and replay readers and the chat prompts all take the log file. The 172 tasks that existed at the start, and W172, W174, W175, W176 and W177 that came from main in later rebases, were moved with `tree.py splitlog` with `load` unchanged for each; main was last read at the merge of W177, and a task that lands after that is moved by hand with `splitlog`. The Goal was met, except that W173's own task file keeps a `## Log` because the installed older tool still appends the runner's lines there, the installed guard cannot read log files so the author chose to merge once with its check skipped, and the web page and screen were checked through their state, not in a browser.

## Goal

move the item log into a separate file that isn't loaded by default
