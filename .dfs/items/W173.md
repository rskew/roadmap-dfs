# W173 · move the item log into a separate file that isn't loaded by default

## Summary

Each task's log now lives in `.dfs/items/<task>.log.md` (`<task>/<tag>.log.md` on a branch), so the task file a session reads holds the Goal and the Tree and no longer grows with every runner line. All 172 existing tasks in this tree were moved with `tree.py splitlog`, and `load` gives the same status, sessions, raises and log entries for every one before and after. `load` merges the log file with any `## Log` left in a task file and the archive, so the web page and terminal screen show what they did, and the commit guard (also at a rebase stop), the uncommitted-work classifier, carry, delete, archive, the audit, history and replay readers and the chat prompts all take the log file. The Goal was fully met; a task file that reaches main after this branch branched (W172, W174, W175, W176) is still moved by hand with `splitlog`, to avoid merge conflicts with a bulk move, and the web page and terminal screen were checked through the state they draw from, not by opening a browser.
