# W127 · Fix the bug raised in W122.5

## Summary

The commit-time check no longer refuses a commit made by hand during a rebase. Such a commit sits on a detached HEAD, and the check read every node it replays as newly added there, so it failed the rule that a branch writes only its own part; while a rebase is in progress the check now skips the writer, Hypothesis and Ask rules, as it already did for a merge, and still applies the shape, history, attachment and size rules. The Goal is met: a test reproduces the refusal without the change and passes with it, and a plain commit on a detached HEAD is still refused. The missing git identity the raise also mentioned is a property of the sandbox, not of the tooling, so it was left alone; and `git rebase` itself never ran the hook, so nothing changed there.
