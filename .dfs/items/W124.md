# W124 · chat should work with kiro and codex and opencode and claude

## Summary

Chat now works under all four agents at their current pinned versions: codex, claude and kiro-cli already passed their live chat tests, and opencode 2.1.1 was fixed to read its new session store, accept its stream, and run each turn and the screen's chat on a private server so scratch homes do not collide. opencode's private server sometimes crashes in Bun (a bug in opencode's runtime, not in this code), so a headless turn is run again when it ended before it began and the tests restart a screen whose server was lost; the live opencode chat test passed 7 of 7 full runs under heavy host load, so the crashes are survived and not prevented, and the cause is not known (reading the store fast was suspected, and 120 turns per pace did not reproduce a crash at any). A stopped or timed-out opencode turn removes its temporary files, a retry is not skipped on the strength of a store that could not be read, and a message resent after a turn that stored no answer is shown once. The screen's opencode runs on a private server for isolation: under one HOME the shared service works as well, but it keeps the config of the process that started it and fails for a second HOME, and a TUI whose private server crashed still hangs for a real user, with no recovery outside the tests (left that way on the assumption that the user reopens it, for the author to rule on); conversations stored by opencode 1.x are no longer read, and the live opencode, codex and claude tests were not rerun in the final sessions beyond opencode's.
