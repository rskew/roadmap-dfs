# W177 · tui should start scrolled to the top, not the bottom

## Summary

The TUI now opens with the item list scrolled to its top. The list is drawn upside down, so the cursor used to start on the first item at the bottom and pushed a long list's window down with it. It now starts on the top row, which is the last item in the work order. I took "the top" to mean the item list, and left the log panes opening at their end, since they do that on purpose.

## Goal

tui should start scrolled to the top, not the bottom

Status: confirmed
Approach: **The question**
- At launch, which view of `scripts/tui.py` shows its bottom: the item list, the item detail, or a log pane?

**What this node does**
