# W41 · Show at least one line of item name

## Summary

A finished task collapsed in the web app's list now always has its name on a whole line of its own, cut with an ellipsis at the row's edge, and its status and tags (unpushed commits, uncommitted edits) always sit on the line under it, even when they would have fitted beside it. A task's own screen already shows the name in full in its heading, so the bar change tried first was taken back out. The layout was checked in the browser list flow, which passes in a rendered page. Only the web list was changed; the terminal list's rows were left as they are, since they have no collapsed done rows.

## Goal

Show at least one line of item name
