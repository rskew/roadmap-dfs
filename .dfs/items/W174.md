## Tree

### W174.1 · Attach pictures in the web chat box
Status: confirmed
Approach: **The question**
- The task page already lets the author attach a picture to a correction or answer, but the chat box has no Attach button. Can the chat reuse that path?

**What this node does**
- In `scripts/web/index.html`, `attachTo` gets an option so the chat box can use it: pictures only, with the bar placed under the box. The chat form wraps so the bar sits on its own line. The picture goes to `/api/attach` and its reference (`![name](.dfs/artefacts/<uuid>.png)`) lands in the message text, so the agent, which runs in the same folder, can read the file by that path.
- A message the author sent is drawn with each picture reference as a small image (tap opens it full size in a new tab), not as raw text. It does not depend on which task is open, so the project chat works too.
- `ui_flows.mjs` and `test_ui.py` get a chat flow: attach by button, paste and drop, and check the sent message draws the picture.

**How we will know it worked**
- The new chat flow passes (needs node and a browser), and `test_web.py` still passes.

Determination: The chat box attaches pictures by button, paste and drop, and sent messages draw them; the new flow passes and fails without the change.
