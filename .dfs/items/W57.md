# W57 · Going back from an item flashes the index then the item then settles on the index

## Summary

Going back from a task with the page's Back button used to push the list onto the history again, so a further Back in the browser or on the phone landed on the task and then the list: the index, the item, the index. Back now steps back in history when the entry beneath is the screen it goes to (the list from a task, the task from a node sheet), and replaces the screen only when a reload or a link opened it. The Goal was read as that doubled history; no visible flicker was seen in the headless browser, so a flash from some other cause would not be covered.
