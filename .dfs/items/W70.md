# W70 · On the tui the chat line wrapping seems buggy. Agent output is ok but the input lines and other lines don't seem to wrap properly

## Summary

In herdr, a chat opened with `c` told the agent the terminal was one column wider than it was, so its rules ran over onto a second row and the input line came out garbled. The screen now sets the agent's size from the terminal as it stands once the attach settles, and in herdr the chat wraps at the pane's width as claude run directly does. The Goal was met for this cause only: it was reproduced and fixed in herdr, not in other terminals, and relaying through the screen was kept, since the author's fallback of starting separate sessions from the screen was only for the case that it could not be reproduced.
