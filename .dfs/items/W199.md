# W199 · Option to un archive chats

## Goal

Option to un archive chats

## Tree

### W199.1 · Server: unarchive a chat
Status: confirmed
Approach: **The question**
- Today a chat leaves Archived only when a message is sent to it. How does the author bring one back without sending a message?

**What this node does**
- `scripts/chat.py`: add `Chats.unarchive(scope)`. It refuses a chat that is not archived, takes off the `ended` mark (as `reopen` already does for a sent message), logs it, calls `on_change` and returns the state.
- `scripts/web.py`: add `POST /api/chat/unarchive` beside `chat/end`.

**How we will know it worked**
- New tests in `scripts/test_chat.py` and `scripts/test_web.py`: archive, unarchive, then the chat reads `ended` false and its messages are kept; unarchiving a chat that is not archived gives 409.
Determination: `Chats.unarchive` and `POST /api/chat/unarchive` bring an archived chat back in progress with its conversation kept, and refuse one that is not archived; the new tests passed.

### W199.2 · Page: an Unarchive button
Parent: W199.1
Status: open
Approach: **What this node does**
- `scripts/web/index.html`: in the chat sheet, the Archive button reads "Unarchive" and calls `/api/chat/unarchive` when the chat is archived (`st.ended`), so it is never greyed out for an archived chat. The Chats list redraws after it.

**How we will know it worked**
- Extend the `chat_end` flow in `scripts/ui_flows.mjs`: open an archived chat, press Unarchive, see the server asked and the chat move out of the Archived group.

### W199.3 · Screen: unarchive from the chats pane
Parent: W199.2
Status: open
Approach: **What this node does**
- `scripts/tui.py`: new key `U` (free today), the opposite of `E`. In the chats pane it acts on the chat under the cursor, elsewhere on the item's chat. It asks first, calls `Chats.unarchive`, and says so when the chat is not archived. Add it to the key table.

**How we will know it worked**
- A test in `scripts/test_screen.py` beside the `E` ones; then the whole suite (`scripts/test_all.py`) passes.
