# W45 · Show the logs of runs

## Summary

A task's page on the web now lists the chains that worked it under Runs, newest first, with whether each is live, finished or stopped, its run number, mode and how long ago it started. Tapping one opens its console log as a screen of its own, wrapped for a phone; for a live chain it keeps growing by itself without losing the reader's place. The server reads a log by the run directory's name only, never a path, and the README says anyone who can reach the page can read these logs. The terminal already showed run logs, so it was left alone; the work reads "show the logs of runs" as the web page's gap, and the agent transcripts under each run (the terminal's second log kind) are not on the web page.

## Goal

Show the logs of runs
