Hypothesis: "Rich text" means the markdown the task files and chat replies already use (backticks, bold, fences, lists, links), not images, tables or HTML. Wrong if the author wants tables, images or raw HTML shown.
Evidence:

- against: italics were left out, since `*` also appears in globs such as `scripts/*.py`, so `*text*` would be mangled.
Determination: Every prose site on the web page (goal, sections, node cards, raises, chat replies) now draws code, bold, links, lists and fences from escaped text; the new richtext flow goes red on the old page and green on this one, and the 7 browser tests that fail here also fail without the change.
