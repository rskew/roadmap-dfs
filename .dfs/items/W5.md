# W5 · Render rich text

## Summary

The web page and the terminal screen now draw the markdown the task files and chat replies are written in: `code`, **bold**, links, lists and fenced blocks on the page (goal, sections, node cards, raises, chat replies), and code and bold on the terminal (cards, sections, raises). Text is escaped before any markup is added, so nothing a file holds can run on the page. Italics, tables, images and headings were left out: `*` also appears in globs like `scripts/*.py`, and the files use none of the others. The terminal does not draw links, lists or fences specially, since its lines carry one style each and its wrapped text already reads as a list; the browser flow for the page was run here, but the terminal look was checked by a drawing test, not by eye.
