# W65 · Custom background for this dfs instance with extension of icon theme

## Summary

This instance's web page now has its own background: one branching tree drawn in the app icon's vocabulary (a square root, stepped runs, amber nodes where it forks, red stopped branches and blue ends), spread across the whole page as a single connected picture, one for light mode and one for dark, under the page's usual veil so text stays readable. It needed no code, only the two pictures in `.dfs/` and the script that grows and draws the tree (`.dfs/background-src`). I read "extension of icon theme" as carrying the icon's drawing and colours into the background; if the app icons themselves were meant to follow the project's colour, or only a flat colour was wanted, those readings are set aside as alternatives. The tree is one fixed random growth picked for reaching every edge, not a hand design, and the page was seen in a headless browser, not on a phone. ![light mode](.dfs/artefacts/7d3e91c4-2b58-4f06-9a1d-6c8e0f5b2a73.png) ![dark mode](.dfs/artefacts/e19a40b8-6c37-4d52-b0f9-3a5d8c1e7f64.png)
