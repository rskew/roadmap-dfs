# W65 · Custom background for this dfs instance with extension of icon theme

## Summary

This instance's web page now has its own background: one branching tree drawn in the app icon's vocabulary (a square root at the centre, stepped runs, amber nodes where it forks, red stopped branches and blue ends), spread across the whole page as a single connected picture, one for light mode and one for dark, under the page's usual veil so text stays readable. The picture is square so a portrait phone, which shows only its middle, still sees the root and a connected part of the tree. It is faint, because the page's fixed 90% veil lets only a tenth of it through; a stronger look would need a code change to the veil. It needed no code, only the two pictures in `.dfs/` and the scripts that grow and render the tree (`.dfs/background-src`, run as its docstring says). I read "extension of icon theme" as carrying the icon's drawing and colours into the background; if the app icons themselves were meant to follow the project's colour, or only a flat colour was wanted, those readings are set aside as alternatives. The tree is one fixed random growth picked for reaching every edge, not a hand design, and the page was seen in a headless browser at phone and desktop sizes, not on a real phone. ![phone light](.dfs/artefacts/5a2c7e91-3d84-4b60-8f1e-9c0b6a4d2e17.png) ![desktop dark](.dfs/artefacts/a97d3c20-6b1e-48f5-9e02-d4c8b1f6a753.png)
