# W81 · Enable chat with codex and others

## Summary

The chat on the web page and the screen's `c` chat now work under codex, opencode and kiro as they do under claude: each scope has one conversation that keeps the agent it began with, the page names that agent, and a message typed on one side shows on the other. The screen's chat for a scope runs the conversation's own agent even after `x` names another; a message sent while a new codex, opencode or kiro chat is still running its opening summary waits for the agent, and when that opening turn fails the page says why instead of showing the message as sent. Real codex, opencode and kiro-cli programs were driven against stand-in model servers (no login for any of them works here) to check page turns, resuming on the screen in both directions, the interrupt keys each agent needs, and messages sent while a chat starts. The Goal was met as read; several agents taking part in one conversation was not built since nothing asked for it, and a logged-in account's own kiro session and replies were not seen, only kiro's shapes as a real kiro-cli writes them.
