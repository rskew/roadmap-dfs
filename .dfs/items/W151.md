# W151 · The walk form should show the parameters used for the walk when walking. Is there model reverting to the default after the first session?

## Summary

The plan model covers only the session that plans a task, the critic and the review; the implement model covers every other session, so a plan model set alone is followed by sonnet. A second cause was found: a walk on kiro was never told a model at all, so choosing opus did nothing and kiro ran on its own default. Kiro is now given `--model` when one is chosen, each agent keeps its own choice, and the two model fields are drop-downs of that agent's models. The walk box also shows, for each running chain, its task, run, kind of session, agent and recorded model. The drop-downs were not tried in a browser here (no playwright), only their rendering under node.

## Goal
