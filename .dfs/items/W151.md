# W151 · The walk form should show the parameters used for the walk when walking. Is there model reverting to the default after the first session?

## Summary

The model does change after the first session, by design: the plan model runs the session that plans a task and the critic and review, and the implement model (sonnet unless set) runs every other session, so a plan model set alone is followed by sonnet. The walk box now shows, for each running chain, its task, run, kind of session, agent and the model the runner recorded for that session, so the form no longer shows only the settings for the next chain. The two model fields still set the next chain, and the rule that opus plans and sonnet implements is unchanged. The existing walk flow in the browser tests already failed on a digit-typing check before this work; it was left alone.
