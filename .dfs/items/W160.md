### W160.1 · Link each chat row to its item
Status: confirmed
Approach: **The question**
- How does the web Chats list (`drawChats` in `scripts/web/index.html`) link each line to the item its chat is about, when the row is already a button that opens the chat?

**What this node does**
- Wraps each row in a `div.crow` and puts an `<a href="#/t/<scope>">` over the row's id column, since a link cannot sit inside a button. The id text is drawn once, in the link. The project chat has no item and gets no link.
- Extends the `chat_end` flow in `scripts/ui_flows.mjs` (it mocks the chats list): the item's row has one link with the right href, the project row has none, no link sits inside a button, and a click on the link opens the task and not the chat.

**How we will know it worked**
- `chat_end` passes, and the other chat flows give the same result as before the change.
Determination: Each item's chat line in the Chats list now has a link to that item (the project chat has none), and `chat_end` passes; a screenshot could not show it because the headless browser here draws no text.
