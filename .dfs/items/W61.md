# W61 · Chat: add button to scroll to top of current message

## Summary

The chat now has a ↑ Top button in its bottom bar. It scrolls the conversation to the top of the message you are reading: the latest message when you are at the end of the chat, otherwise the one at the top of the view, and pressing it again steps back to the message before. It also holds while the agent is working: the log is no longer pulled back to the bottom by each "Thinking…" refresh unless you were already at the end or have just sent a message. "Current message" was read as the one in view, since the Goal does not say; the change is confined to the web page and covered by a browser test.

## Goal

Chat: add button to scroll to top of current message
