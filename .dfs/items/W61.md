# W61 · Chat: add button to scroll to top of current message

## Summary

The chat now has a ↑ button in its bottom bar, an arrow alone because a word beside it read as the top of the whole chat. It scrolls the conversation to the top of the message you are reading: the latest message when you are at the end of the chat, otherwise the one at the top of the view, each further press stepping back to the nearest message above, or to the top of the log from inside a note above the first message. It holds while the agent is working, because the log is no longer pulled back to the bottom by each "Thinking…" refresh unless you were already within 80px of the end or have just sent. "Current message" was read as the one in view, and a scrolled-up reader is no longer carried to the end while the agent works; the Goal says neither, so both are written down for the author to confirm or change at .dfs/artefacts/81962c04-e937-49aa-800d-341c4076ce04.html. The change is confined to the web page and covered by browser tests for the button, for when the log follows the end, and for the four-button bar fitting a 320px screen.
