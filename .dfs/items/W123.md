## Summary

The web task list now has a **Table** button, shown on screens 1012px wide and up (a scrollbar not counted), that draws one line per task with a column each for status, review, branch and run, wide enough to show their tags whole, and lets the list take the page's width so the goal keeps 245px to 405px or more. The author chose this style (D) from four drawn on a proposals page; the terminal list was left as it is, and the phone, screens under 1012px, Reorder and the archived tasks still draw the card, as does a list column that a scrollbar leaves under 980px. A blocked or running task keeps its reason on a line under its row. The Goal asked for proposals and they were made and one built; the layout was finally seen in a browser given a font, and a row with two branch tags or four status tags is still cut (its title says the whole).
