# W123 · Propose a few different styles for the item list

## Summary

The web task list now has a **Table** button, shown on screens 900px wide and up, that draws one line per task with a column each for status, review, branch and run; it is kept in the browser and the card stays the default. The author chose this style (D) from four drawn on a proposals page; the terminal list was left as it is, and the phone, Reorder and the archived tasks still draw the card, as does a list narrowed by an open task. A blocked or running task keeps its reason on a line under its row. The Goal asked for proposals and they were made and one built; the layout could not be seen, because the browser available here draws no text, so only the row markup is tested (under node), not the column widths.
