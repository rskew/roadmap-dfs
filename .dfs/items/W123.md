# W123 · Propose a few different styles for the item list

## Summary

The Goal asked for a few styles for the item list. Four were drawn on proposal pages, first for the terminal and then, once the author said the terminal list is fine, for the web list as real rows in the app's own look. The author picked the table, and the web list now has a **Table** button on screens 1012px wide and up (a scrollbar not counted): one line per task with columns for status, review, branch and run, the goal taking the rest of the page width, and a reason line under a blocked or running task. The phone, narrower screens (a classic scrollbar on a 1012px to 1026px screen counts against the width), Reorder and archived tasks still draw the card, each filled cell carries a hidden column name for a screen reader, and the terminal list is unchanged.
