# W62 · Confirming a node whose siblings are actioned should ask the user to confirm parking them

## Goal

Confirming a node whose siblings are actioned should ask the user to confirm parking them

## Tree

### W62.1 · Name the later siblings a confirmation would prune and that hold work
Status: confirmed
Approach: In scripts/tree.py add `actioned_siblings(t, nid)`: the live later siblings of node nid (same Parent and tag, higher n, not pruned or deleted) that are actioned, meaning confirmed, refuted or started, or having such a node among their descendants. It returns [] unless confirming nid would prune (`keeps` is false). Unit tests in scripts/test_tree.py cover an open sibling, a parked one, a ruled one, an open one with a ruled child, a started one, an earlier sibling, another tag's sibling and an already-confirmed node.
Hypothesis: "Parking" the siblings means what confirming already does to them (the later siblings are pruned, since a determined node cannot be edited into parked), and "actioned" means ruled on, started, or holding such a step, so open and parked siblings are pruned without a question. Wrong if the author wants every later sibling asked about, only the ruled ones, or the siblings written as parked in the file. .dfs/artefacts/cca4654e-4875-459a-9743-bd9ad046c635.html
Evidence:
- for: scripts/test_tree.py passes (98 tests) with three new ones: only the ruled, started and ruled-child siblings are listed, the earlier, open and parked ones are not, and a refutation or an already-confirmed node lists none.
- for: `effective` (scripts/tree.py) already prunes exactly the later same-parent same-tag siblings and their subtrees on a confirm, and nothing in the file can be edited to parked once determined, so pruned is the only parking there is.
Determination: `actioned_siblings` lists the later live siblings a confirmation would prune that hold work, and nothing when it prunes none; the tests pass, so the web, server and terminal asks are built on it.

### W62.2 · The server refuses a confirmation over actioned siblings until parking them is agreed

The task JSON gives each node row `parks`. Tests in scripts/test_web.py.
