# W76 · Remove the first steps section when creating a task. Users can add nodes for explicit steps.

## Summary

A new task is now made with only its name, its Goal and an optional draft box: the web page's form no longer has a First steps box, and the steps are added afterwards as nodes. The Goal named the web form; the same list of steps also went from the terminal's `run.sh --open` prompt, from `/api/new`, from the function that writes the task file and from the project chat's instructions, so a task made any way starts with an empty tree. If you wanted the terminal to keep asking for steps, that is the one part to put back.

## Goal

Remove the first steps section when creating a task. Users can add nodes for explicit steps.
