# W67 · Reenable the shell tool in chat sessions

## Summary

The web page's chat turn (`run.sh --chat-turn`), the one chat that had no shell, now allows the Bash tool, so a page chat can run commands to look at the project as the screen's chat always could. Edit, Write and NotebookEdit are still refused and the permission-skipping flags are still not passed, but Bash itself is unrestricted, so a command can change files; only the turn's framing asks the agent not to. The comments, docstrings and a test now say this plainly. It was checked against a stub claude, not a real one, and the Goal's shell is the only tool added.
