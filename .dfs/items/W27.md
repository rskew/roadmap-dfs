# W27 · Show if items are not on origin/main

## Summary

Each task in the web list and the terminal list now says when some of its node commits, or uncommitted edits to its task files, are not on the remote default branch ("3 not on origin/main" and "uncommitted edits, not on origin/main" on the web, "ahead 3 +edits" in the terminal), and every commit line on an opened node says so when that commit is not there. The default branch is read from git (where origin/HEAD points, then init.defaultBranch, then main or master), so a repo on master works. It compares HEAD with that ref as last fetched and never fetches, so a push made elsewhere shows only after the next fetch. The Goal was met; the web page was not rendered in a browser.

## Goal

Show if items are not on origin/main
