# W163 · Rename walk work

## Summary

The depth-first runner formerly called "walk" is now called "trek" everywhere a person or the code meets it: the module `scripts/trek.py` and its tests, the `trek_*` names and constants, the `/api/trek` routes, the screen and web page text, the README, SKILL.md and the docs. The old `--no-walk` flag still works as an alias for `--no-trek`. The Goal gave no new word, so I chose "trek" and the alias myself; the answer page asks the author to confirm or refute that. Left alone on purpose: `os.walk`, "walk" used as an ordinary verb, the research data files under `docs/`, and the history in `.dfs`.
