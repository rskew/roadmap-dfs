# W163 · Rename walk work

## Summary

The depth-first runner formerly called "walk" is now called "work", the word the author gave, everywhere a person or the code meets it: the module `scripts/work.py` and its tests, the `work_*` names and constants, the `/api/work` routes, the screen and web page text, the README, SKILL.md and the docs, including the browser drivers `docs/ux-*.py` (`docs/ux-web-work.py` is the renamed walk driver; it compiles but could not be run, as the sandbox has no playwright). The old `--no-walk` flag still works as an alias for `--no-work`. Because Enter was already the screen command `work`, the `w` command is now named `work-all` so that `:work` and the palette stay unambiguous. Left alone on purpose: `os.walk`, "walk" as an ordinary verb, the research data files under `docs/`, and the history in `.dfs`.

## Goal

Rename walk work
