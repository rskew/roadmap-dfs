Option to hide non assumption nodes

## Tree

### W16.1 · tree_entries can list only the nodes that want the author
Status: confirmed
Approach: In `scripts/tui.py`, `tree_entries(t, folded=(), flagged=False)` with `flagged=True` drops every node row that is not an assumption (⚑), an ask, or the carrier of an open raise; section rows and task-level raise rows stay, and a kept node keeps its depth and its `kids` count. `test_review_tree.py` pins it: a mixed tree keeps only the flagged nodes, and the default is unchanged.
Hypothesis: "Assumption nodes" means the nodes the screen already marks as wanting the author: ⚑ assumption, ? ask, or an open raise on the node; ancestors of a kept node are not kept. Wrong if the author meant only nodes with a Hypothesis (asks and raises hidden too), or wants the path down to each kept node shown.
Evidence:
- for: `state` marks a node `assumes` only while it is not refuted, pruned or ruled on (`dfs_tree.assumed`), so the same rows the screen already flags in amber are the ones kept; the test with a mixed tree passes (43 in `test_review_tree`).
- against: the Goal says only "assumption nodes"; asks and raises are included by my reading, not by anything the author wrote.
Determination: Confirmed: `tree_entries(..., flagged=True)` keeps only assumption, ask and raise-bearing nodes with folds off and `kids` 0, and the default rows are unchanged.
Ask: Should the flagged view also keep the ancestors of a flagged node for context? I chose not to, so it is a flat list of the nodes that want you.
