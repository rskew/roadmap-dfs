# W120 · Remove confirmation on start walk

## Summary

The web page's Start walk button, and Enter in the Budget or Chains field, now start the walk at once instead of opening a "Start the walk?" dialog. Starting or stopping a walk folds the walk box shut, and stopping no longer shows a toast. The permission-prompts warning that the dialog carried now sits in the note under the Start button. A second click while the start is in flight is ignored. Start still shows its "Walking." toast, and the per-task "Stop chain" dialog is unchanged, since the Goal names only the walk's own controls (.dfs/artefacts/9edb0d40-7aeb-4bf0-8aec-4ea163ca58c2.html lets you overrule that). Only the web page changed; the terminal screen already starts a walk without a confirmation, so it was left alone. The ui_flows.mjs walk flow could not be run (no node or playwright here), so it is read but unrun; instead a test in test_web.py runs the page's walk functions in headless chromium, and a text test covers the warning note and the missing dialog.

## Goal

Remove confirmation on start walk, starting walk and stop walk collapses walk menu, remove toast on stop walk
