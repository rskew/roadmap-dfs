# W120 · Remove confirmation on start walk

## Summary

The web page's Start walk button, and Enter in the Budget or Chains field, now start the walk at once instead of opening a "Start the walk?" dialog. Starting or stopping a walk folds the walk box shut, and stopping no longer shows a toast. The permission-prompts warning that the dialog carried now sits in the note under the Start button. A second click while the start is in flight is ignored. Only the web page changed; the terminal screen already starts a walk without a confirmation, so it was left alone. The browser flow for the walk could not be run in the session that finished it, since no browser was available, so that flow is read but unrun; a text test covers the warning note and the missing dialog.

## Goal

Remove confirmation on start walk, starting walk and stop walk collapses walk menu, remove toast on stop walk
