# W75 · Items should be completed in git branches, passing review merges the branch into main/master

## Summary

Each item is worked on its own branch, `dfs/<task>`, in a worktree under `.dfs/worktrees/<task>`, and a passing review or the author's accept rebases it onto `main` or `master`, merges it with `--no-ff` and removes the worktree and branch. The Goal was met, and the branch now sits on current main with its merge and the size rule both working. Off main or master, or with no commit yet, an item is still worked in place, since there is nothing to cut a branch from.
