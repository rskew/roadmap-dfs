# W75 · Items should be completed in git branches, passing review merges the branch into main/master

## Summary

Each item is worked on its own branch in a worktree; a passing review or the author's accept rebases it onto `main` or `master`, merges it with `--no-ff` and removes the worktree and branch. The Goal was met; off main or master, or with no commit yet, an item is still worked in place.
