# W11 · Can't edit items

## Summary

The web page can now edit what it shows: "Edit task" changes a task's name and Goal, and "Edit" on an open or parked node changes its title and Approach. Confirmed and refuted nodes cannot be edited, because a determined node is history; add a node instead. The Goal's wording was only "Can't edit items", so I took it to mean the web page, since the terminal already opens an item's file in `$EDITOR`. The dialogs' JavaScript was not run in a browser here (none was available); the server side is tested.
