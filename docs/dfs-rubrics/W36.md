# W36 rubric · "Chat should have an interrupt button"

Written from the Goal and the starting code, before any replay was scored. Not read for it: any replay tree
or task file. Seen before writing: the original run's Summary of this task. At the starting commit the web
page's chat dialog (`#chat` in `scripts/web/index.html`) sends a message to `scripts/chat.py`, which runs one
agent turn (`run_turn`) per message and has no way to end it; a chat can also be running in the terminal's own
process (`running_elsewhere`), and a conversation is resumed by its session id.

| # | Clause (met only if wholly true) |
|---|---|
| C1 | The web chat dialog shows an interrupt (stop) control while the agent is answering, and does not offer it, or shows it disabled, when no turn is running. |
| C2 | Pressing it ends the agent turn that is running for that chat (the process or its process group is stopped), through a route in `scripts/web.py` and a method in `scripts/chat.py`. |
| C3 | After a stop the chat is usable: the person can send another message, the earlier messages stay, and the conversation is resumed or restarted so the next turn works. This holds when the stop came during the first message of a new chat, before any session id was saved, as well as in a later turn. |
| C4 | The chat log shows the stopped turn as stopped (a plain note), not as a failure or an error message, and the dialog stops showing it as busy. |
| C5 | A stop pressed when no turn is running (idle, already finished, or twice) does nothing harmful: no error, no signal sent to an unrelated process. |
| C6 | A stop reaches only the process of the chat it was pressed for: another chat's turn, running at the same time, is untouched. |
| C7 | For a chat that is running in the terminal's own process (not started by the page), the control either interrupts it by a stated, working means or is clearly unavailable; it never kills the terminal's process or fails silently. |
| C8 | The control is reachable on a phone-size layout, is labelled for a screen reader and meets the page's touch-target size, in the dialog's existing style. |
| C9 | A test exercises the stop path (a turn started, stopped, and the chat used again). |
