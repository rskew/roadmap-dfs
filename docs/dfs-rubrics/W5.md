# W5 rubric · "Render rich text"

Written from the Goal and the starting code, before any replay was scored. Not read for it: any replay tree
or task file. Seen before writing: the original run's Summary of this task. At the starting commit the web
page already draws markdown in chat replies only (the `md()` function of `scripts/web/index.html`); the task
text it shows (a task's Goal, the nodes' Approach, Hypothesis, Determination, raises, titles) is plain, and the
terminal screen (`scripts/tui.py`) shows markdown markers (`**`, backticks) as typed. "Rich text" is read as the
markdown the task files and the chat replies are written in.

| # | Clause (met only if wholly true) |
|---|---|
| C1 | On the web page, `inline code` in the task text (Goal, node sections, raises) is drawn as code, not as backticks. |
| C2 | On the web page, `**bold**` in that task text is drawn bold, not with asterisks. |
| C3 | On the web page, `[text](url)` is drawn as a link in that task text, and a `javascript:` (or other script) URL is not made into a link. |
| C4 | On the web page, bulleted and numbered lines are drawn as lists. |
| C5 | On the web page, fenced code blocks are drawn as preformatted blocks, with the text unchanged inside them. |
| C6 | Text is escaped before markup is added: a task file holding `<script>` or `<img onerror=...>` is shown as typed and runs nothing, in every place the renderer is used, chat replies included. |
| C7 | The terminal screen no longer shows the raw `**` and backtick markers in the task text it draws (cards, sections, raises, titles): it draws them styled or removes them. |
| C8 | Plain text is not mangled: a glob such as `scripts/*.py`, an identifier such as `snake_case_name`, an unmatched `**` or backtick, and `2 * 3 * 4` are shown as typed. |
| C9 | The chat reply renderer that already existed is still used where it was (the same or a shared renderer): chat replies still draw fences, code and bold. |
| C10 | A test exercises the renderer on a markdown input and on an input with markup that must be escaped. |
