# W3 rubric · "Walk failed when started from the page, error fetching nixpkgs for the agent process, truncated sha?"

Written for W153 before any W3 replay was run or scored. Written from the Goal (a walk started from the page failed
with an error fetching nixpkgs for the agent process; the author suspects a truncated sha) and the starting code at
35c343dc, where `scripts/agent.py` `main()` prints only the last line of nix's stderr as `dfs_agent: <arg> failed: ...`
and `update()` shows `rev[:12]` in its success message. Not read for it: any replay tree, and the original W3 tree's
code. Either way of meeting the Goal counts: a clearer message, a fix of a real truncation, or both.
