# W4 · Verify tokens safely

## Summary

Token verification now compares the MAC in constant time and rejects tokens whose expiry has passed. A token is still accepted for 30 seconds after its expiry, covering clock skew between hosts, and a non-numeric expiry is rejected. The Goal was fully met and tests cover both fixes.

## Goal

auth.verify has two holes: it compares the MAC with != and it never checks the expiry in the token. Close both. Clock skew between our hosts is up to 30 seconds, so a token that expired a few seconds ago on one host must still work on another.
