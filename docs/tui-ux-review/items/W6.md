# W6 · Upstream timeouts

## Summary

server.handle now gives up on a hung upstream after 2 seconds and returns (504, 'upstream timeout'). The fetch runs on a daemon worker thread, so the request thread is freed, and a late result from the abandoned fetch is discarded and never reaches the cache. The Goal was fully met; the abandoned fetch thread itself cannot be killed and runs until the upstream returns.

## Goal

When the upstream hangs, server.handle hangs with it, and since each request holds a thread the gateway runs out of threads within minutes. Make handle give up after 2 seconds with a 504 and free its thread's work. Done = a hung fetch yields (504, 'upstream timeout') in about 2s, and the cache is not poisoned by the failure.

### W6.4 · Concurrent requests for one hung path each wait 2s in turn, not 2s total
Parent: W6.2
Status: confirmed
Approach: src/server.py handle runs the 2s timer inside cache.get_or_set's compute, which holds the per-key lock (src/cache.py). A timeout is not cached, so every queued request for the same path gets the lock in turn and starts its own fetch and its own 2s wait. Checked with a scratch script: 4 concurrent handle calls on one hung path returned 504 after 2.0, 4.0, 6.0 and 8.0s, so the Goal "give up after 2 seconds" fails for all but the first, and queued threads stay held (the very exhaustion the Goal names). Fix so every caller gets 504 within about 2s of its own start (for example a total deadline, or waiting for the lock with a timeout, or sharing the in-flight fetch's result/failure), and add a test with several concurrent handles on one hung path asserting each returns 504 in under about 3.5s.
Determination: Fixed with a total deadline set at handle's start (src/server.py): the compute passes the remaining time to _fetch_with_timeout, which raises TimeoutError without starting a worker once it is spent. The new test with 4 concurrent handles on one hung path failed on the old code and now passes, each 504 within 3.5s (full suite 21 passed). Next, the minor findings.
